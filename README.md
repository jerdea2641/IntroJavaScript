# Jeremy Dean's Portfolio

## Overview
This portfolio displays information about me and my software development projects. Projects are created using JavaScript objects and displayed dynamically.

## Languages and Technologies
- HTML
- CSS
- JavaScript
- DOM
- sessionStorage
- localStorage

## Dependencies
- A modern web browser.
- No external libraries or frameworks are required.
- Project images must be in the same folder as HomePage.html.

## How to Run
1. Keep HomePage.html and the project images in the same folder.
2. Open HomePage.html in a web browser.
3. The Projects section will display the project information.
